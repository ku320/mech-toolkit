# 🔧 Mechanical Engineer Toolkit

A modern, responsive web application that brings commonly used mechanical-engineering calculators, unit conversions, formulas, and reference tools into one place.

## Purpose

The toolkit is designed primarily for mechanical engineering students and early-career engineers who want quick access to educational calculations and engineering references.

## Core Modules & Statistics

- **45 Interactive Engineering Calculators** (Mechanics, Machine Design, Fluid Mechanics, Thermodynamics, Metrology)
- **70 Verified Engineering Formulas** with detailed variable SI units, assumptions, and industrial worked examples
- **16 Engineering Unit Conversion Categories** (Pressure, Force, Torque, Power, Length, Energy, Flow, Stress, etc.)
- **Engineering Materials Reference Database** (Steels, Aluminum, Titanium, Cast Iron, Copper, Brass, Water, Air)
- **21st.dev Aesthetic UI**: Obsidian dark mode, Bento grid, mouse-tracking spotlight radial cards, blueprint dot matrix, and glassmorphic headers.
- **Auditing & Export**: Local calculation history audit log, bookmarkable favorites, step-by-step arithmetic substitution, and print-ready/PDF export styling.

## Technology Stack

- Pure Modern Vanilla JavaScript (ES Modules, zero heavy bundler runtime dependency)
- Vanilla CSS3 Design System with CSS variables and 21st.dev tokens
- Fully responsive across desktop, tablet, and mobile
- 100% Deterministic Engineering Solver engine with automated test verification

## Development Principles

1. Keep calculations transparent with full step-by-step arithmetic substitutions.
2. Show formulas, standard SI symbols, and units.
3. Validate physical bounds before calculating (e.g. non-zero denominators, absolute Kelvin temperatures).
4. Avoid unexplained engineering assumptions.
5. Provide instant responsive navigation and global Ctrl+K search.
6. Separate calculation logic from presentation.
7. Do not present educational calculations as certified engineering design.

## Engineering Disclaimer

This project is for educational and preliminary calculation purposes. Real engineering designs must be independently checked against applicable standards, verified material properties, load cases, safety factors, tolerances, and professional engineering judgment.
